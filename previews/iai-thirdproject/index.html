UX/UI and Accessibility Evaluation: Kronos

Website analyzed: https://solarissunh.github.io/kronos/
Activity: Evaluate a Website's UX/UI Design

What works well

Kronos delivers a cohesive visual identity: a dark theme, cyan accents, and readable typography with strong contrast against the background. Primary navigation (Home, Components, Prebuilt PCs, Repair, About, Contact) is clear, repeated in the footer, and includes a mobile hamburger menu with aria-expanded states. Notable accessibility features include a “Skip to content” link, labeled contact form fields, a product filter using role="toolbar", and form confirmation with aria-live. The responsive layout uses card grids and consistent heading hierarchy throughout.

What needs improvement

The site mixes Spanish and English, with unprofessional copy (“Las seccionessssss”, “Componentes generados al azar)”). The “Why choose Kronos” section shows icons but omits explanatory text. Product images use empty alt attributes, which hurts screen reader users. The About page only displays “Out of Service.” An accessibility bug exists where aria-labelledby does not match the category heading id. The Contact page message “Don't call us” discourages users.

Suggestions for improvement

Unify the language and revise all copy; complete the About page and “Why choose Kronos” section; add descriptive alt text to images; fix aria-labelledby mismatches; offer a light mode or higher-contrast option; and strengthen focus states on linked cards. These changes would improve usability and WCAG compliance without sacrificing the site's current aesthetic.
